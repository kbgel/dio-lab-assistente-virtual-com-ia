# Skill: Explicar Conceito de Segurança

Explica um conceito de segurança digital de forma clara e didática, ajustada ao nível do cliente.

## Quando usar

O cliente perguntou o que é algo relacionado a segurança (phishing, token, CVV, autenticação, cartão virtual, etc.), disse que não entendeu um termo, ou demonstrou confusão sobre um conceito.

## Processo

### 1. Descubra o ponto de partida

Antes de explicar, tente entender o que o cliente já sabe. Se não for possível perguntar, assuma que ele tem pouca familiaridade técnica. Consulte `data/perfil_investidor.json` para verificar o perfil do cliente.

### 2. Dê uma definição simples

Explique o conceito em uma ou duas frases, sem jargão. Se precisar usar outro termo técnico, explique-o também.

### 3. Use uma analogia do dia a dia

Conecte o conceito a algo que o cliente já conhece. Exemplo: "O CVV é como a senha do cadeado da sua bicicleta — quem tem, consegue usar."

### 4. Mostre um exemplo prático

Dê um exemplo concreto de como aquele conceito aparece no dia a dia do cliente. Use situações reais: receber uma mensagem, fazer uma compra, acessar o app.

### 5. Aponte o risco de não saber

Explique brevemente por que entender aquele conceito protege o cliente. Sem alarmismo.

### 6. Verifique o entendimento

Termine confirmando se ficou claro ou se o cliente quer outro exemplo.

## Lembre-se

- Comece simples. É sempre possível aprofundar depois.
- Nenhuma dúvida é boba. Toda pergunta é válida.
- Uma boa analogia vale mais que um parágrafo de teoria.
